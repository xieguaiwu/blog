# 关于本站

这是一个用 [Hexo](https://hexo.io/) + [Butterfly](https://butterfly.js.org/) 搭建的个人博客。
版式与交互参考了 [着火的冰块nya 的小家](https://zhdbk3.github.io/)（[源码](https://github.com/zhdbk3/zhdbk3.github.io)），
按自己的口味重做了配色与背景。

## 艺术混搭背景

站点背景是 16 套手工合成的艺术拼贴，**每次加载随机切换一张**。素材取自公有领域（public domain）的西方绘画，
分四种拼法：

| 样式 | 说明 | 套数 |
| :--- | :--- | :--- |
| A 单幅满铺 | 一幅画作满屏，加暗角与胶片颗粒 | 4 |
| B 主画 + 细节拼贴 | 暗化的主画作底，四周嵌金边细节小图 | 4 |
| C 三联祭坛画 | 三幅竖构图并置，金色分隔线，暗底 | 4 |
| D 层叠蒙太奇 | 主画之上以羽化蒙版叠印作品，做显影感 | 4 |

出现过的画家包括：Böcklin、Goya、Delacroix、Stuck、Moreau、Simberg、Ensor、Cabanel、
Van Gogh、Kokoschka、Bosch、Tanner、Waterhouse、Roberts。

窄屏（≤ 768px）会自动改用竖版变体，避免宽幅拼贴被裁掉主体。
