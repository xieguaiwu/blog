# About This Site

A personal blog built with [Hexo](https://hexo.io/) + [Butterfly](https://butterfly.js.org/).
Inspired by [zhdbk3.github.io](https://zhdbk3.github.io/) (MIT), with custom colors and backgrounds.

## Artistic Collar Background

The site features 16 sets of hand-crafted artistic collages as backgrounds, **randomly selected on each page load**. All source material is from public domain Western paintings, combined in four styles:

| Style | Description | Count |
| :--- | :--- | :--- |
| A — Full Bleed | Single painting full-frame with vignette and film grain | 4 |
| B — Main + Details | Darkened main painting with gold-framed detail insets | 4 |
| C — Triptych | Three vertical compositions side by side, gold dividers | 4 |
| D — Layered Montage | Feather-masked overprints for a "developing" effect | 4 |

Featured artists include: Böcklin, Goya, Delacroix, Stuck, Moreau, Simberg, Ensor, Cabanel, Van Gogh, Kokoschka, Bosch, Tanner, Waterhouse, Roberts.

On narrow screens (≤ 768px), vertical variants are automatically swapped in.
